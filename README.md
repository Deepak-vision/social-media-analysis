# Social Media Analysis Using SQL

## Project Overview
This project focuses on analyzing social media platform data using SQL to understand user activity, engagement patterns, popular hashtags, trending posts, and follower relationships.

## Database Structure
The database consists of seven relational tables:
- Users
- Posts
- Likes
- Comments
- Followers
- Photos
- Photo_Tags

## Objectives
- Identify active users.
- Analyze post engagement through likes and comments.
- Identify popular hashtags.
- Find trending and highly engaging posts.
- Analyze follower relationships.

## SQL Concepts Used
- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- Aggregate Functions
- INNER JOIN and LEFT JOIN
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions (RANK, DENSE_RANK, ROW_NUMBER)

## Key Analysis
The project explores user activity, post engagement, hashtag popularity, and follower patterns to generate meaningful insights.

## Tools Used
- Database: MySQL
- Language: SQL
- Platform: MySQL Workbench

## Conclusion
This project helped develop practical SQL skills and understand how relational database analysis can generate insights into social media user behavior and engagement.
